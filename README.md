# Isle — мод для Minecraft Forge 1.20.1

## Что внутри
- **Винтовка** — точная, дальность 96, урон 10, полуавтомат.
- **Пистолет-пулемёт** — очередь из 3 выстрелов на один клик.
- **Дробовик** — 8 дробинок, мощный вблизи.
- **Патроны**: винтовочные, для ПП, картечь (у каждого оружия свой тип).
- **Сталкер** — высокий монстр, спавнится в тёмных местах Верхнего мира, накладывает «Тьму». Яйцо призыва есть в креативе.
- **Дневники** — выпадают из Сталкера (всегда) и из других монстров (6%). Правый клик читает следующую запись.
- **Счётчик смертей** — после каждой смерти пишет номер и причину («учись на каждой смерти»).
- **Бинт** — лечит 6 HP.
- Вступление при первом входе. Креатив-вкладка «Isle». Рецепты крафта для всего.

Оружие ломать нельзя, оно требует патроны в инвентаре (в креативе патроны не нужны).

## Как собрать
1. Скачай MDK Forge **1.20.1-47.3.0** (files.minecraftforge.net) и распакуй.
2. Скопируй папку `src/` из этого архива поверх `src/` в MDK (удали пример `examplemod`).
3. В `gradle.properties` MDK поставь значения из `gradle.properties.example` (mod_id=isle и т.д.).
4. Нужна Java 17. В папке MDK: `gradlew build` — готовый jar будет в `build/libs/`.
   Для теста: `gradlew runClient`.
5. Jar положи в папку `mods/` Forge 1.20.1.

## Крафт
- Винтовка `IIB / ST_`, ПП `IBI / TS_`, Дробовик `IIB / BST` (I = железо, B = железный блок, S = палка, T = крючок растяжки).
- Винтовочные патроны ×8: порох + железо + медь. Патроны ПП ×12: порох + железо + золотой самородок. Картечь ×4: порох + бумага + железный самородок.
- Бинт ×2: 2 бумаги + нитка.
